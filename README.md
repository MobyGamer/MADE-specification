# MADE: Measure of AI in Design & Execution

MADE is a self-disclosure AI rating scale for creative and technical works that separates human conceptual authorship (Ideation / Design) from mechanical production (Execution).  For more information as well as an interactive builder for MADE disclosures, visit https://mobygamer.github.io/MADE-specification/

The canonical MADE specification is located in MADE-SPECIFICATION.md, which can be referenced as a "ground truth" document for MADE.

## AI Usage Disclosure

[![MADE: I0 / E0,E2-E3](images/made-badge.svg)](https://mobygamer.github.io/MADE-specification/)

This work is self-disclosed under the **MADE (Measure of AI in Design & Execution)** standard:
- **Ideation (`I0`, Unassisted):** 100% human-originated concepts, designs, compositions, and algorithms.  Zero AI consultation.
- **Execution (`E0,E2-E3`, Unassisted, Collaborative, Directed):** Project components span multiple execution levels (E0,E2-E3: Unassisted, Collaborative, Directed). See the component breakdown for details.

### Component Breakdown

| Component / Deliverable | MADE Score | Classification | Details |
| :--- | :--- | :--- | :--- |
| **MADE Specification** | **`I0 / E0`** | Ideation: Unassisted; Execution: Unassisted | Specification design, wording, and markdown "ground truth" document all written by a human. |
| **MADE Landing page** | **`I0 / E2`** | Ideation: Unassisted; Execution: Collaborative | Landing page design, layout, and non-interactive elements were design by a human, partially executed by AI. |
| **MADE Interactive Builder** | **`I0 / E3`** | Ideation: Unassisted; Execution: Directed | Interactive builder, including purpose, colors, text, and behavior, was designed by a human; AI built most of the HTML/CSS/logic. |
