## 1. Software & Programming Scenario (`AIDR: I0,I1 / E0,E3`)

*Scenario: An independent developer designs an original software project and writes the performance-critical core engine entirely by hand (`I0 / E0`), while using an LLM to generate secondary data-conversion utilities from a detailed human specification (`I1 / E3`).*

### 1.1 Markdown Table (`README.md`)

```markdown
## AI Usage Disclosure: AIDR `I0,I1 / E0,E3`

This project is self-disclosed under the **[AIDR (Artificial Intelligence Disclosure Rating) v1.0](AIDR-SPECIFICATION.md)** standard:

| Component | AIDR Score | Classification | Details |
| :--- | :--- | :--- | :--- |
| **Core Engine & Algorithms** | **`I0 / E0`** | Unassisted Ideation, Unassisted Execution | Conceived, architected, and hand-coded 100% by the human author with zero AI involvement. |
| **Data Conversion & Build Utilities** | **`I1 / E3`** | Assisted Ideation, Directed Execution | File formats and conversion logic were designed by the human author (`I1`), and the utility scripts were generated by an LLM from detailed human specifications and verified by hand (`E3`). |
| **Documentation & User Manual** | **`I0 / E0`** | Unassisted Ideation, Unassisted Execution | Written and edited manually by the human author. |
```

### 1.2 Per-File Source Code Header Tags

**For Hand-Crafted Core Source Files (`.c`, `.cpp`, `.rs`, `.asm`):**
```c
// AIDR-Usage: I0/E0 (Ideation: Unassisted, Execution: Unassisted)
// Note: 100% human-designed and hand-written source code. Zero AI involvement.
```

**For Spec-Driven AI Utility Scripts (`.py`, `.js`, `.sh`):**
```python
# AIDR-Usage: I1/E3 (Ideation: Assisted, Execution: Directed)
# Note: Implemented by an LLM strictly from technical specifications and
# constraints designed and verified by the human author.
```

## 2. Creative Writing & Publishing Scenario (`AIDR: I1 / E0,E1`)

*Scenario: An author writes an original novel, investigative essay, or tabletop RPG rulebook. The plot, characters, and prose are written by hand, while AI is used only to summarize historical research material (`I1`) and act as an interactive phrase thesaurus and proofreader (`E1`).*

### 2.1 Copyright Page / Book Colophon / Article Footer

```markdown
**AI Disclosure (AIDR v1.0: `I1 / E0,E1`):**
Ideation 1 (Assisted), Execution 0, 1 (Unassisted, Assisted).
All plotlines, characters, arguments, and prose in this work were conceived and written by the human author. AI tools were consulted solely for background historical research (`I1`) and used during editing as an interactive phrase thesaurus and grammar checker (`E1`). No AI-generated prose is present in this publication.
```

### 2.2 Detailed Breakdown for an Anthology or Tabletop RPG Book (`AIDR: I1,I2 / E0,E2`)

```markdown
## AI Usage Disclosure: AIDR `I1,I2 / E0,E2`

| Component | AIDR Score | Classification | Details |
| :--- | :--- | :--- | :--- |
| **Core Narrative & Prose** | **`I1 / E0`** | Assisted Ideation, Unassisted Execution | Story, dialogue, and lore were written 100% by hand (`E0`), with AI used only for historical fact-checking (`I1`). |
| **Worldbuilding & Encounter Tables** | **`I2 / E2`** | Collaborative Ideation, Collaborative Execution | Secondary setting locations and random encounter tables were co-brainstormed (`I2`) and co-drafted (`E2`) between the author and an LLM. |
```

## 3. Graphical & Visual Art Scenario (`AIDR: I0,I1 / E0-E2`)

*Scenario: A visual artist or indie comic creator designs and illustrates all characters, line art, and key scenes by hand (`I0 / E0`), uses ML denoising/upscaling on final exports (`I0 / E1`), and uses AI-assisted texture tiling for repetitive background patterns (`I1 / E2`). Because Execution spans `E0`, `E1`, and `E2` continuously, it is expressed as the contiguous range `E0-E2`.*

### 3.1 Portfolio / Artbook / Storefront Disclosure

```markdown
## AI Usage Disclosure: AIDR `I0,I1 / E0-E2`

| Artwork Component | AIDR Score | Classification | Details |
| :--- | :--- | :--- | :--- |
| **Character Design, Line Art & Key Illustrations** | **`I0 / E0`** | Unassisted Ideation, Unassisted Execution | 100% conceived, sketched, inked, and painted by hand by the human artist. |
| **High-Resolution Print Exports** | **`I0 / E1`** | Unassisted Ideation, Assisted Execution | Hand-painted illustrations processed through a non-generative machine-learning upscaler and denoiser for print preparation. |
| **Repeating Environmental Textures** | **`I1 / E2`** | Assisted Ideation, Collaborative Execution | Secondary background surface patterns created through a hybrid human-AI texture workflow and manually composited into scenes. |
```

## 4. Music Composition & Audio Production Scenario (`AIDR: I0,I2 / E0,E1`)

*Scenario: A musician composes and performs an album or soundtrack. Most tracks are 100% human-composed and performed on physical instruments (`I0 / E0`), room noise on acoustic recordings is cleaned up using a neural audio restoration plugin (`I0 / E1`), and one bonus track features chord variations co-brainstormed with an AI tool but performed by the human musician (`I2 / E0`).*

### 4.1 Album Liner Notes / Bandcamp / Streaming Description

```markdown
## AI Usage Disclosure: AIDR `I0,I2 / E0,E1`

- **Lead Compositions & Instrumental Performances (`I0 / E0`, Unassisted Ideation, Unassisted Execution):** All melodies, arrangements, lyrics, and instrumental performances were composed and played by the human artist.
- **Harmonic Variations on Track 7 (`I2 / E0`, Collaborative Ideation, Unassisted Execution):** Alternate bridge chord voicings were co-brainstormed with an AI assistant (`I2`) and performed manually on hardware synthesizers by the artist (`E0`).
- **Audio Restoration & Mastering (`I0 / E1`, Unassisted Ideation, Assisted Execution):** Acoustic microphone recordings were processed with a neural de-reverb and noise-reduction filter during mixing (`E1`). No generative AI audio or synthetic vocals are used on this release.
```
