## 2. General Reusable Templates for Other Projects

### 2.1 Purely Hand-Crafted Code or Writing with AI Diagnostics/Research (`I1 / E1`)
Use this when both the ideas and the code/writing are yours, and AI was only used as a reference tutor, bug-checker, phrase thesaurus, or audio/transcript cleanup tool.

```markdown
**AI Disclosure (AIDE v1.0: `I1 / E1` — Assisted Ideation, Assisted Execution):** All concepts, designs, and source code/prose in this work were authored by the human creator. AI tools were used strictly for background reference lookups, read-only bug/diagnostic review, or non-generative signal cleanup. No generative AI code or prose was copied into the final release.
```

### 2.2 Purely Human Project with Zero AI (`I0 / E0`)
Use this to positively assert zero AI involvement in either ideation or execution.

```markdown
**AI Disclosure (AIDE v1.0: `I0 / E0` — Unassisted Ideation, Unassisted Execution):** Created 100% by a human with zero AI involvement in concept, research, design, or implementation.
```

### 2.3 Core Human Code + AI Helper Scripts/Charts (`I1 / E2`)
Use this when you wrote the primary application or article yourself, and used AI to generate secondary scripts, test harnesses, or charts/diagrams from your data.

```markdown
**AI Disclosure (AIDE v1.0: `I1 / E2` — Assisted Ideation, Collaborative Execution):** All core architecture and primary code/prose were authored by the human creator (`I1 / E0–1`), while generative AI was used to produce secondary helper scripts, test harnesses, or data visualizations (`E2`).
```
